PRIVACY

Small, first-party, and optional.

BranchScript keeps diagrams local by default and asks before counting anonymous visits.

Necessary storage

The editor uses browser storage to keep local projects and preferences. If you sign in, the server sets a Secure, HttpOnly, SameSite cookie so it can authenticate your requests. JavaScript cannot read that session cookie.

Optional anonymous analytics

Only after you accept, BranchScript creates a random first-party visitor identifier for 180 days. The server stores the identifier, visit date, broad page area (site or app), page-view count, and the two-character country code supplied by our edge network. It does not store diagram content, email, IP address, full URL, or browser fingerprint in the analytics table.

Operational logs

The hosting and security infrastructure may process standard request information, including an IP address and browser user-agent, in operational access and security logs. Those logs are separate from the consented anonymous visit totals described above.

Your choice

Choosing “Necessary only” disables the anonymous counter and removes its cookie. You can change the choice at any time.
