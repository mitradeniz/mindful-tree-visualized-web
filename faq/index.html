FREQUENTLY ASKED QUESTIONS

What can you map with BranchScript?

Quick answers about the language, visual builder, algorithms, privacy, storage, and deployment.

What is BranchScript?

BranchScript is a visual thinking workspace and a small text language for describing connected diagrams. It supports thought trees, process flows, neural-style maps, logic paths, pseudocode algorithms, and data structures on an infinite canvas.

Do I need to learn scripting before using it?

No. The visual builder can add boxes, choose their types and styles, and connect them. It writes the equivalent BranchScript into the editor, so you can learn from the changes while continuing visually.

How is this different from a question-and-answer tool?

The interview view focuses on answers you could give and the routes those answers create. You can connect each possible response to follow-up questions, evidence, trade-offs, and alternative answers rather than storing one ideal response.

Can BranchScript visualize brainstorming and idea maps?

Yes. Thought trees capture alternatives, flow and logic views expose dependencies and decisions, and the live runner tests one path through the idea. Tags, status, priority, color, and shape help distinguish assumptions, evidence, active work, and outcomes.

Can I visualize pseudocode algorithms?

Yes. The algorithm view includes start, function, operation, condition, loop, and return nodes. Named connections can represent true/false branches, repeated loops, early returns, and error paths.

Which data structures are supported?

The data view provides visual types for arrays, indexed items, stacks, queues, linked lists, records, and pointers. These can be connected to explain state, ownership, references, and traversal.

What does the live playground do?

It finds valid starting nodes and lets you choose the next connected branch. The active path is highlighted on the canvas. This is useful for rehearsing interview answers, testing logic, and teaching algorithm control flow.

Where are my diagrams stored?

The editor automatically keeps a local copy in your browser using IndexedDB. You can export a plain .mtree source or a project bundle. If you create an account, private cloud diagrams can also be saved to Neuralith’s backend.

How is browser authentication protected?

The browser session uses a host-only Secure, HttpOnly, SameSite=Strict cookie. The token is not exposed to JavaScript or stored in localStorage. Diagram endpoints validate the BranchScript application claim, request origin, and record ownership.

Is BranchScript mobile friendly?

Yes. On small screens the editor and canvas use focused tabs, toolbars simplify to touch-sized primary actions, horizontal templates remain scrollable, and account, builder, guide, and live-run panels become mobile sheets.

Does the project use React?

No. The application is written in TypeScript with native web APIs, Vite, CodeMirror, AntV X6, Dagre, Lezer, and Zod. The public project documents the licenses of bundled dependencies during production builds.

Can I self-host it?

The public repository includes the complete local-first editor and its static web container. Cloud accounts and remote diagram storage require a separate backend implementation.
