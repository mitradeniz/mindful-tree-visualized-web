THE .MTREE LANGUAGE

A readable script that remains a diagram.

BranchScript files are plain UTF-8 text with the .mtree extension. They are parsed as data, never executed as JavaScript, and every visual edit is written back to the same source.

interview.mtreeTree · top down
diagram interview "Backend Interview"
@view tree

question intro "Tell me about yourself"
response concise "Backend-focused answer"
@text "Keep it under two minutes."
@answer "I build reliable APIs..."
@feature "Follow-up: ownership"
@priority high
followup scale "How did it scale?"
example result "Reduced p95 by 38%"

USE OR SELF-HOST

Start in the browser. Install only if you want to.

The hosted playground needs no account for local diagrams. Developers can run the public frontend from source or build the hardened static Nginx container.

DockerBuild the static app
git clone https://github.com/mitradeniz/mindful-tree-visualized-web.git
cd mindful-tree-visualized-web
docker build -t branchscript .
docker run --rm -p 8080:8080 branchscript

Open http://127.0.0.1:8080/. Production Compose can attach the same image to a reverse-proxy network.

What works without the private backend?

Editing, templates, Live Run, local saving, import, and export work independently. Email accounts and private cloud diagrams require the separately maintained backend service.
